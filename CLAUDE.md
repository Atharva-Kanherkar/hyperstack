## Claude-specific notes

- Prefer Socratic teaching: ask what they tried before giving hints.
- When the human asks you to “implement X,” check whether X is the **core learning objective** of the active `projects/pXX-*` folder. If yes, refuse the full implementation and offer a scaffold/interface + review instead.
- Comparison branches (e.g. “now show LangGraph version”) are allowed **only** when explicitly requested, and must live beside the hand-coded solution, not replace it.
- Keep replies concise; put durable notes into the project README, not only chat.
- Do not create extra markdown docs unless asked.
